🔧 Nodes do N8N (Workflow)

Cada bloco é um passo no fluxo automatizado

TRIGGER

Webhook / Olaclick

Recebe dados do lead automaticamente quando alguém clica no Olaclick

AÇÃO

WhatsApp Send Message

Envia mensagem personalizada usando a API do WhatsApp Business

LÓGICA

IF / Switch

Divide o fluxo conforme resposta do cliente: qualificado / não qualificado / sem resposta

AÇÃO

Google Sheets / CRM

Salva lead com nome, telefone, interesse, data e status da conversa

AÇÃO

Delay / Follow-up

Espera X minutos/horas e envia nova mensagem se cliente não respondeu

AÇÃO

HTTP Request

Busca dados extras do Olaclick, cardápio ou sistema King Food via API

AÇÃO

Telegram / Notificação

Envia alerta para você quando um lead quente precisa de atenção humana

LÓGICA

AI Agent (Opcional)

Usa IA para entender mensagens livres e responder de forma natural
